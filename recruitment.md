# Recruitment portal and assessment

**Problem.** Agency onboarding needed a traceable intake, approval, and code issuance workflow.

**My contribution.** I supported requirements and rollout coordination for consultant onboarding. I also worked on assessment requirements covering mandatory questions, CV data capture, and result classification for review.

**Design.** Capture candidate details, validate required inputs, assign the approving authority, and record the decision before issuing a code. Keep assessment, onboarding approval, and downstream compensation decisions as distinct workflow events.

**Illustrative acceptance checks**

- An incomplete assessment cannot be submitted.
- A reviewer can correct an extracted CV field before it is used in the workflow.
- Issuance records contain the candidate reference, approval decision, and approval timestamp.

**Project stage represented.** Consultant code issuance went live. Assessment work covered requirements and testing coordination.
