# Offline performance letter generation

**Problem.** Recurring performance and validation letters needed consistent wording and formatting across different audiences and reporting scenarios.

**Work represented.** An offline browser prototype for preparing template-based letters from structured inputs, with multiple iterations and dedicated rendering checks.

**Workflow.** Select the audience and reporting scenario, map input fields to the corresponding template, review the generated letter, and check the final output before release.

**Illustrative acceptance checks**

- A missing required field is flagged before generation.
- Each audience receives the correct template for its reporting scenario.
- Headers, bullet lists, and substitutions render correctly in the final output.
- The workflow can run without a network connection.

**Stage.** Offline prototype and rendering QA. Production use and time savings were not measured here.
