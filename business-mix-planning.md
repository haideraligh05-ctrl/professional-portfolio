# Business mix and shortfall planning

**Operations analytics project · Offline browser prototype**

Sales teams need to see how an available pipeline might close a performance gap. The prototype compares scenarios using opening and closing values, completed production, and expected pipeline.

**Demonstration scenario.** Enter a sample target and a limited pipeline, then compare a minimum-volume plan, a balanced mix, and a plan using all available opportunities. The tool keeps residual gaps visible and supports exporting scenarios for later review.
