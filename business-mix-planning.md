# Business mix and shortfall planning

**Operations analytics project · Offline browser prototype**

Sales teams need to see how an available pipeline might close a performance gap. The prototype compares scenarios using opening and closing values, completed production, and expected pipeline.

**Demonstration scenario.** Enter a sample target and a limited pipeline, then compare a minimum-volume plan, a balanced mix, and a plan using all available opportunities. The tool keeps residual gaps visible and supports exporting scenarios for later review.

## Worked example: limited coverage

A team has a target of 100 performance units and 65 already recorded. Its starting shortfall is 35 units. The available pipeline contains 20 units from one category and 10 from another.

| Scenario | Pipeline credited | Projected total | Residual shortfall |
| --- | ---: | ---: | ---: |
| Recorded performance only | 0 | 65 | 35 |
| First category only | 20 | 85 | 15 |
| All available pipeline | 30 | 95 | 5 |

Even with full delivery, the pipeline leaves a five-unit gap. A manager can use that gap to size the additional pipeline required. This illustration uses synthetic performance units and assumes every available unit is eligible.
